AUTOATELIER – Demo-Website

Dateien:
- index.html: Struktur, Inhalte und SEO-Metadaten
- style.css: Design und responsive Layouts
- script.js: mobiles Menü und dynamische Jahreszahl

Lokal testen:
1. Alle drei Dateien im selben Ordner belassen.
2. index.html per Doppelklick im Browser öffnen.
3. Fenster verkleinern und mobiles Menü ausprobieren.
4. Alle Navigationslinks sowie E-Mail- und Telefonlinks anklicken.
5. Optional: im Projektordner 'python3 -m http.server 8000' starten und http://localhost:8000 öffnen.

Für die Veröffentlichung:
- Demo-Mailadresse und Demo-Telefonnummer ersetzen.
- Echten Standort und verbindliche Preise eintragen.
- Platzhalter in der Galerie durch eigene Bilder ersetzen.
- Individuelle Rechtstexte (Impressum und Datenschutzerklärung) ergänzen.
- Falls gewünscht, eine eigene Domain-/URL-Angabe (canonical, OG-URL) ergänzen.
- Die drei Dateien per FTP in das Webverzeichnis hochladen.

Keine Frameworks, Schriften-CDNs, externen Skripte, Tracker oder bezahlten Abhängigkeiten.

LANGUAGE DROPDOWN / SPRACHAUSWAHL
Im Header zwischen DE · Deutsch und EN · English wechseln. Die Auswahl wird
sofern möglich im Browser gespeichert (localStorage). Die Übersetzungen stehen
in script.js; die deutschsprachige Version bleibt ohne JavaScript lesbar.

Use the dropdown in the header to switch between German and English. The selected
language is remembered in the browser when storage is available.
